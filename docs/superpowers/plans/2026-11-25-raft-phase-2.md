## قراردادها (Interfaces — دقیقاً طبق پلنِ مادر)

```python
# messages.py — همه dataclass
RequestVote(term, candidate_id, last_log_index, last_log_term)
VoteResponse(term, vote_granted: bool)
AppendEntries(term, leader_id, prev_log_index, prev_log_term, entries, leader_commit)
AppendResponse(term, success: bool, match_index: int)

# network.py
@dataclass
class Envelope: from_id, to_id, payload, sent_at, deliver_at
class Network:
    def send(self, from_id, to_id, payload, now, rng) -> None   # deliver_at = now + U(5, 20)
    def deliver_due(self, now) -> list[Envelope]                # به‌ترتیب deliver_at
    def set_link(self, i: int, j: int, up: bool) -> None        # لینک پایین ⇒ drop + event "dropped"
    def pending(self) -> int

# node.py
class RaftNode:
    PERSISTED = ("current_term", "voted_for", "log")   # بعد از kill/restart می‌مانند
    def __init__(self, node_id: int, cluster, rng: random.Random) -> None
    def tick(self, dt_ms: float) -> None
    def receive(self, msg) -> None
    def submit(self, command: str) -> int              # فعلاً فقط در صورت Leader بودن، وگرنه RuntimeError

# cluster.py
class Cluster:
    def __init__(self, n: int = 5, seed: int = 42) -> None
    now: float                     # زمان شبیه‌سازی (ms)، از 0
    def tick(self, dt_ms: float) -> None
    def kill(self, node_id: int) -> None               # volatile ریست؛ persisted می‌ماند؛ تا restart تیک نمی‌خورد
    def restart(self, node_id: int) -> None
    def set_link(self, i: int, j: int, up: bool) -> None
    def on_event(self, cb) -> None                     # cb(dict) — رویدادها: sent, delivered, dropped, down, up
```

**ثابت‌های pin شده:** تأخیر شبکه U(5, 20)ms · تایمر انتخابات U(150, 300)ms (فقط سیم‌کشی، منطق کامل فاز ۳) · heartbeat 50ms · ایندکس لاگ از ۱ · sentinel ایندکس ۰ ترم ۰ · اکثریت پیش‌فرض برای ۵ گره = ۳.

## ریسک‌ها و ددبندها

- شبکه دوطرفه نیست اگر کسی `set_link` را یک‌طرفه صدا بزند → لینک را متقارن نگه دار؛ تست ۶ پوشش می‌دهد.
- flakiness از تصادفی بودن delay → همه‌جا seed ثابت؛ هیچ تستی به ساعت واقعی وابسته نیست.
- scope creep به انتخابات → هیچ منطقی فراتر از step-down ساده با Term بالاتر در این فاز نیست.
